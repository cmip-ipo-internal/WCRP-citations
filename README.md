# citation-mapper

## Branch Setup

This repository uses the following branch structure:

- **src-data** (default/main branch) - Primary development and data source branch
- **production** - Production-ready code

### Setting Up Branches

To set up the required branches, run:

```bash
./setup-branches.sh
```

For detailed manual instructions, see [BRANCH_SETUP.md](BRANCH_SETUP.md).

**Note:** Setting the default branch to `src-data` requires repository admin access and must be done through the GitHub web interface or API.
